# Fridays Gehirn (KI-Kern)

Ab Version 1.126.0 hat Friday ein eigenes Gehirn-Fenster.

## So öffnest du es
- Werkzeug-Menü → **Friday** → **Fridays Gehirn**
- Seitenleiste → **System** (der erste Reiter heißt jetzt **🧠 Gehirn**)
- Sprache: „Friday, zeig mir dein Gehirn“, „öffne den KI-Kern“ oder „was denkst du gerade?“

## Was du siehst
Oben ein gebogener Glas-Bildschirm, darunter Leitungen zum leuchtenden Gehirn auf dem Sockel.
Alle Zahlen sind echt, nichts ist ausgedacht:

| Anzeige | Woher die Zahl kommt |
|---|---|
| Neuronale Aktivität | Einträge im Logbuch in der letzten Stunde |
| Wissensspeicher | Dinge, die Friday sich gemerkt hat, und gespeicherte Gespräche |
| Verbindung | Ist Claude erreichbar (Guthaben)? Ist der Mac verbunden? |
| Lernstatus | Wie viel Friday diese Woche neu gelernt hat |
| Neuronale Pfade | Eingang → Gehirn-Zentren → Ausgang, je dicker, desto mehr Arbeit in 7 Tagen |
| Automatischer Ablauf | Analyse → Verarbeitung → Entscheidung → Aktion, leuchtet live, während Friday denkt |
| Aktivität heute | Einträge pro Stunde |
| Mac-Auslastung | Prozessor und Speicher der letzten Minuten |
| Datenstrom | Die letzten Dinge aus dem Logbuch |
| KI-Leistung | Anteil der Aufträge heute, die ohne Fehler geklappt haben |
| Gehirn-Zentren | Sprachzentrum, Logik & Analyse, Emotionen & Kreativität, Erinnerungen, Handeln |
| Energie | Dein Claude-Guthaben aus dem Energie-Fenster |

Tipp: Tipp oder fahr mit der Maus auf ein Zentrum, dann leuchtet genau dieser Bereich im Gehirn auf.
Die Lichtimpulse im Gehirn werden schneller, je mehr Friday zu tun hat, und rasen, während Friday gerade nachdenkt.

Im Leistungsmodus „Flüssig“ zeichnet Friday weniger Nervenzellen, damit das iPhone nicht warm wird.
